# review-survey

Read CLAUDE.md and docs/cli.md. Read the affected project or survey first. Use the operator name as an audit label and only supplied facts. Run:

```bash
npm run surveys -- review-survey --survey=SURVEY --evidence="Checks performed against original evidence" --actor="Reviewer name"
```

Only record the operator's completed review. A different named reviewer must have checked evidence and permission scope. Record checks are not legal or ecological certification.
